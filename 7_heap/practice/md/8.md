_Практика 7. Binary heap._

# Задача 2 - Решение.

## Вариант решения 1

Создать из массива min-кучу. Заполнить результирующий массив беря элементы из кучи.

## Вариант решения 2

Первый вариант решения предпологает использование дополнительной памяти. Этого можно избежать, используя следующий алгоритм:

1) создаём max-heap, последовательно вызывая функцию `heapify` начиная от конца массива
    * после этого в массиве на индексе 0 окажется максимальный элемент
2) поменяем местами корневой элемент кучи с последним элементом кучи
    * теперь последний элемент кучи находится в правильном положении
3) уменьшаем размер кучи на 1 с конца - "удаляем" последний элемент, находящийся в правильной позиции в массиве
4) восстанавливаем свойство кучи с момощью функции `heapify`
5) повторяем пункты 2-4, пока в куче не останется один элемент

> Работоспособность пункта 1 обослувлена тем, что функция `heapify` восстанавливает свойство кучи для бинарного дерева, если такое свойство соблюдено для всех поддеревьев. Вызывая `heapify` начиная от листьев дерева и заканчивая корнем можно восстановить свойство кучи для всего дерева.


Детали - [heap-sort.](https://www.geeksforgeeks.org/heap-sort/)
