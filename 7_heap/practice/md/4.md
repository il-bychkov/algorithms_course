_Практика 7. Binary heap._

# Задача 0 - Решение.

## Вариант решения 1

Создать `n` куч. Заполнять результирующий массив беря максимальный элемент из `n` куч, каждый раз сравнивая `n` элементов и находя максимальный из них.

## Вариант решения 2

Вместо непосредственного сравнения `n` элементов можно реализовать структуру данных, которая будет хранить `n` куч в куче. При получении максимального элемента сначала выполняется операция `heapify` для кучи из которой был получен максимальный элемент, а затем та-же операция выполняется для кучи в которой хранятся `n` куч.
