# Бонус - Проверка числа на простоту. Необычная реализация.

```python
import re

def check_prime(num):
    is_prime = not re.match(r'^.?$|^(..+?)\1+$', "1"*num)

    if is_prime:
        print(num, "is prime")
    else:
        print(num, "is not prime")
```
